# CF-Pages-SingBoxSH

一个极简的 **Sing-box 一键安装命令生成器**（纯静态网页，无需构建）。

把 [eooce（老王）](https://github.com/eooce) 的 **sing-box 小钢炮** 无交互一键安装脚本的参数，变成几个点选，方便大家使用。本网页是 [cmliu](https://github.com/cmliu) 对该脚本的**拓展 / 二次开发**，仅做参数拼接与可视化，不改变脚本本身的行为。

打开页面只有一个入口：点「添加节点」勾选你想要的节点，底部会实时生成一条可复制的**无交互一键安装命令**，粘到 VPS 上以 root 身份运行即可。不用手工填任何参数，也不会一上来就把一堆配置项铺满屏幕。

## 本地预览

直接双击打开 `index.html` 即可（零依赖、不发任何网络请求、不加载任何第三方资源；`style.css` / `core.js` / `app.js` 都是本地文件）。或在目录下起一个静态服务器：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> 注意：脚本必须用普通 `<script src>` 引入（**不能**用 `type="module"`），否则用 `file://` 双击打开会因 CORS 白屏。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构 + 本地资源引入（只留结构与引入，不含内联 CSS/JS） |
| `style.css` | 全部样式 |
| `core.js` | **纯逻辑层**：状态构造、端口 / UUID 校验、随机取值、命令拼装。无副作用、不依赖 DOM，可被 Node 直接 `require` |
| `app.js` | **界面层**：渲染、事件、持久化、主题、复制 |

## 生成的命令长什么样

例如全部节点开启、Argo 使用固定隧道并填写了 CF 优选：

```bash
UUID=b7e4b1f0-3c2a-4d9e-8f11-2a3b4c5d6e7f NAME=test CFIP=mfa.gov.ua CFPORT=443 HY2_PORT=20100 TUIC_PORT=20200 REALITY_PORT=20300 S5_PORT=20400 ANYTLS_PORT=20500 ANYREALITY_PORT=20600 ARGO_PORT=8001 ARGO_DOMAIN=argo.example.com ARGO_AUTH='tok' bash <(curl -Ls https://main.ssss.nyc.mn/sb.sh)
```

### 变量输出顺序（固定）

```
UUID → NAME → SHOW_LOG → CFIP → CFPORT → HY2_PORT → TUIC_PORT → REALITY_PORT → S5_PORT → ANYTLS_PORT → ANYREALITY_PORT → ARGO_PORT → ARGO_DOMAIN → ARGO_AUTH → DISABLE_ARGO
```

- `UUID` 永远排在最前面，输出为 `UUID=<值>`（不加引号）。
- `NAME`（节点名称）紧跟 `UUID` 之后，输出为 `NAME=<值>`（不加引号）；**留空则完全不输出**该变量。
- `SHOW_LOG`（日志输出开关）紧跟 `NAME` 之后。**默认开启 → 完全不输出该变量**（沿用脚本默认）；只有关闭日志输出时才输出 `SHOW_LOG=false`。它是**全局变量**，与 Argo 是否启用无关。
- `CFIP` / `CFPORT`（「基础配置」组）仅 **Argo 启用时**出现，排在 `UUID` / `NAME` / `SHOW_LOG` 之后、第一个 `*_PORT` 之前；两个都留空则不输出。
- 选中某协议 = 输出它的端口变量；不选则完全不输出。
- `ARGO_PORT` / `ARGO_DOMAIN` / `ARGO_AUTH` 仅在 Argo 启用时出现，位于 6 个直连端口之后。
- Argo 默认安装；删除 Argo 会追加 `DISABLE_ARGO=true`（恒在末位）。
- `ARGO_AUTH` 用英文单引号包裹并按 `'\''` 转义内部单引号；隧道域名 / 密钥留空即使用临时隧道。

## 变量清单

| 变量 | 含义 | 说明 |
| --- | --- | --- |
| `UUID` | 所有节点的全局鉴权标识 | 标准 UUID（8-4-4-4-12 十六进制）；页面会预填一个随机 UUIDv4，留空自动重新生成 |
| `NAME` | 节点名称 / 显示名 | 仅填写时输出，**留空则不输出**（用脚本默认）；只能包含字母、数字、中文、下划线、中划线、点，**不能有空格或 shell 特殊符号**；最长 40 字符 |
| `SHOW_LOG` | 日志输出开关 | **默认开启 → 完全不输出**该变量（沿用脚本默认）；关闭时输出 `SHOW_LOG=false`。与 Argo 是否启用无关 |
| `CFIP` | CF 优选域名 / IP | 仅 Argo 启用时输出；留空则不输出（脚本自带默认值） |
| `CFPORT` | CF 节点对外端口 | 仅 Argo 启用时输出；留空则不输出（脚本自带默认值）；填写时必须为 1–65535 整数 |
| `HY2_PORT` | hysteria2 端口 | 直连 |
| `TUIC_PORT` | tuic-v5 端口 | 直连 |
| `REALITY_PORT` | vless-reality 端口 | 直连 |
| `S5_PORT` | socks5 端口 | 直连 |
| `ANYTLS_PORT` | anytls 端口 | 直连 |
| `ANYREALITY_PORT` | anyreality 端口 | 直连 |
| `ARGO_PORT` | Argo 端口 | 默认 `8001`。**页面默认留空**（输入框以占位符 `8001` 提示），留空则不输出该变量，由脚本用默认 `8001` |
| `ARGO_DOMAIN` | Argo 固定隧道域名 | 与密钥同时填写才生效，否则用临时隧道 |
| `ARGO_AUTH` | Argo 隧道密钥（token 或 json） | 英文单引号包裹 |
| `DISABLE_ARGO` | 不安装 Argo | 删除 Argo 时输出 `true`，恒在末位 |

## 参数组

- **基础配置**（Argo 启用时）：`CFIP` 优选域名 / IP、`CFPORT` 节点端口。两项均**留空即不输出**，由脚本用默认值兜底。`CFIP` 会去除换行 / 制表符并 trim；`CFPORT` 若填写则必须是 1–65535 的整数。`CFPORT` 是 CF 节点**对外**端口，**不参与本地监听端口冲突检测**。
- **端口**：各直连协议与 Argo 的本地监听端口（**UDP 与 TCP 是两套独立端口空间，互不冲突**，详见下节「端口 / UUID 校验与提示」）。
- **节点名称**（UUID 卡片下的「高级设置」，可选）：`NAME`，即节点显示名。**留空即不输出**，由脚本用默认值兜底；只能包含字母、数字、中文、下划线、中划线、点，不能有空格或 shell 特殊符号，最长 40 字符。
- **日志输出**（UUID 卡片下的「高级设置」，可选）：`SHOW_LOG` 开关，**默认开启**（即脚本默认的写日志）。关闭后命令会追加 `SHOW_LOG=false`，脚本不再写日志文件，低配机器运行更省力。开关所在整块区域都可点（点标题 / 开关 / 注释文字任一即可切换）。
- **固定隧道**（Argo，可选）：`ARGO_DOMAIN` + `ARGO_AUTH`，两项需同时填写，否则使用临时隧道。

## 端口 / UUID 校验与提示

- **端口**：必须是 **1–65535 的整数**。`1` 与 `65535` 合法；`0`、`65536`、负数、小数、非数字、含空格（如 `"10000 "`、`" 10000"`）一律非法。
  - 严格性：**不做 trim** —— 含空格即视为非法。
  - **端口冲突按传输方式（UDP / TCP）分组检测**：UDP（`hysteria2` / `tuic-v5`）与 TCP（`vless-reality` / `socks5` / `anytls` / `anyreality`，以及 `Argo`）是两套**互相独立**的端口空间——**同一个端口号在 UDP 和 TCP 上可以合法共存，不算冲突**。只有**同一传输方式内**出现同号端口才判定为冲突，此时会标红冲突双方的输入框、禁用复制，并提示「端口冲突：… 与 … 都使用了 UDP/TCP 端口 …，请改成不同的端口」。
  - 端口输入框内嵌一个**循环箭头图标按钮**：点击即为该输入框随机一个端口，取值范围 **10000–65535**，并会自动避开当前已被占用的端口（**不分传输方式**，UDP / TCP 上用过的号一律避开）。`CFPORT` **不提供**随机按钮（它必须是 CF 支持的端口）。
  - 端口越界、或在**同一传输方式内**与其它端口重复，会标红并禁用复制。
  - **Argo 端口留空 ≠ 不占端口**：留空时脚本会用默认 `8001`，因此该 `8001` 仍视为已占用（**Argo 属于 TCP**）。若把某个 **TCP 直连协议**（`vless-reality` / `socks5` / `anytls` / `anyreality`）手工填成 `8001` 而 Argo 留空，同样会判定为 TCP 端口冲突（Argo 侧提示「留空时默认用 8001，与 … 重复」）；反之把 **UDP 协议**（`hysteria2` / `tuic-v5`）填成 `8001` 则**不冲突**。仅当**移除 Argo** 后 `8001` 才被释放。
- **UUID**：必须是标准 8-4-4-4-12 十六进制（大小写均可，接受任意版本位）。格式非法时输入框标红、给出中文提示并禁用复制。留空会自动生成一个随机 UUIDv4 并回填。
- **错误提示**：端口 / UUID / 节点名称的错误信息以**独立错误行**呈现（仅在有错误时出现、无错误时不占高度），显示中文原因（如「端口与 Argo 重复」「端口超出有效范围」），避免输入框标红却看不出原因。

## 复制命令按钮

两个命令区（「安装命令」「停止命令」）的右下角各有一个绿色的「复制命令」按钮：

- 默认态 = 绿色描边 + 复制图标 + 文案「复制命令」；点击成功后换成**对勾图标 + 「已复制」**（不只靠颜色表达状态），约 1.8 秒后复原。
- 按钮为**纯色**（透明底 + 绿色描边/文字/图标），不使用任何渐变 —— 因而没有渐变按钮常见的「边缘漏色」问题。
- 「安装命令」标题后带一句小字提示「安装完成后，输入 `sb` 可调出脚本菜单」。
- 命令无效时（UUID 非法 / 端口冲突 / 未启用任何节点）按钮会变灰禁用，但「停止命令」的复制始终可用。

## 停止命令

页面在安装命令下方提供一个独立的「停止命令」，内容逐字符为：

```bash
pkill -f '\.tmp/'
```

它是静态的、与节点配置无关，永远可独立复制。

## 一键全选（ALL）

右上角工具栏中间的「ALL」按钮（位于主题按钮与重置按钮之间）＝ **一键全选**：点一下把**全部节点**都加进来。

- 六个直连协议（`hysteria2` / `vless-reality` / `tuic-v5` / `socks5` / `anytls` / `anyreality`）全部启用，并各自随机分配一个端口。
- **Argo 也在全选范围内**（毕竟 ALL 就是全选）。它按「添加节点」的老规矩走：端口保持**留空**，由脚本用默认 `8001`（输入框以占位符提示），所以命令里不会多出多余的 `ARGO_PORT`；若你此前手动移除过 Argo，点 ALL 会把它装回来，`DISABLE_ARGO=true` 随之消失。
- 随机分配会**避开全部已占用端口**，所以六个端口互不重复，也不会撞上已有端口（Argo 留空时占用的 `8001` 同样被避开）。
- **已经启用**的节点保持原端口不变，不会被重置或重新随机。
- 已经全选时再点一次不会有任何改动，只提示「所有节点已经全部启用」。

## 推荐指数（星星）

**已选节点的卡片**和**「添加节点」下拉**里都会在传输气泡右侧紧挨着显示 **5 颗星的推荐指数**，一眼就能看出该协议的推荐程度。

- **满分 5 星，支持半星**（0.5 步进）：例如 4.5 星 = 4 颗实心 + 1 颗半星。
- **纯 SVG 绘制，不是 `★★★★☆` 字符** —— 星形字符在不同平台/字体下形状、大小、甚至是否变成彩色 emoji 都不一样，半星更是只能靠冷门字符（很多设备直接缺字）。用 SVG 能保证所有设备上完全一致。
- 实现方式：每颗星 = 「描边空星」背景层 + 「实心星」前景层，半星用前景层宽度 50% + `overflow:hidden` 裁剪（不用 SVG `clipPath`/`linearGradient`，避免多行 id 冲突）。
- 无障碍：整组带 `role="img"` + `aria-label`（如「推荐指数 4.5 / 5 星」），内部 SVG 全部 `aria-hidden`。
- 星星颜色按**最差底色**取值（行在 hover / 键盘聚焦时会叠一层淡色底），因此浅色下不是最亮的金而是偏琥珀的 `#c2670a`——再亮就会跌破本项目「图形对象 ≥3:1」的对比度底线。
- **打分方式**：改 `core.js` 里每个协议的 `rating` 字段即可（0–5，可写 4.5；越界会自动钳到 0–5，非 0.5 的倍数会就近吸附）。
- **列表顺序也跟着分数走**：「已选节点」与「添加节点」两处列表都是 **Argo 永远置顶**，其余按推荐指数**从高到低**排列；同分时保持 `core.js` 里的声明顺序（顺序稳定，不会每次刷新乱跳）。
  顺序是**由 `rating` 现算**的，所以你改完分数，列表顺序会自动跟着变。
  注意：这只影响**界面展示顺序**，**不影响生成的命令里的变量顺序**（那是固定契约，永远是 `UUID → NAME → SHOW_LOG → CFIP → CFPORT → 6 个直连端口 → ARGO_*`）。

## 主题

- 只保留**浅色 / 深色**两种主题，右上角为图标按钮。**图标表示「点击后会切换到的主题」**：浅色时显示**月亮**（点击切到深色），深色时显示**太阳**（点击切到浅色）。
- **首次进入**按系统主题（`prefers-color-scheme`）自动选择；此后用户手动切换的结果会写入 localStorage 并优先使用。
- 传输分类气泡分色：UDP（hysteria2 / tuic-v5）一色系、TCP（vless-reality / socks5 / anytls / anyreality）另一色系、Argo 用中性第三色。分色与端口冲突的传输分组一致（Argo 用 TCP，故与 TCP 直连协议同组检测冲突）。
- 「添加节点」的下拉面板**复用同一套气泡与简介**：每行是「名称 + 传输气泡 + 简介」，与上方已选节点卡片完全同构（不再有第二套简介文案）。

## 持久化

- UUID、节点名称、日志输出开关（`SHOW_LOG`）、各节点配置（含 `CFIP` / `CFPORT`）、主题会静默保存在浏览器本地，刷新不丢失，右上角可「重置」（重置后日志输出回到默认的**开启**）；旧版本缓存里没有的字段会按默认值兜底（例如缺少日志输出开关时视为开启）。

## 部署

把 `index.html`、`style.css`、`core.js`、`app.js` 一起放到 Cloudflare Pages 即可（无需构建步骤）。
